**Tool Practice – Power BI Integration with Excel**



Objective: Learn to merge Excel datasets into Power BI and create interactive dashboards.



Detailed Learnings:



Imported Excel dataset containing monthly regional sales data.



Cleaned data using Power Query:



Removed null rows.



Normalized region names (e.g., “N” → “North”).



Built a dashboard with two visuals:



Bar Chart: Total sales by region.



Line Chart: Monthly sales trends from Jan–Jun.



Added Slicer for filtering by product category.



Learned differences between Excel vs Power BI:



Excel → great for local analysis, pivot tables.



Power BI → interactive, scalable, easier to share with stakeholders.
