**Video – Power BI for Beginners**



Objective: To gain practical knowledge of building interactive dashboards in Power BI.



Key Learnings \& Outcomes:



Process Overview:



Imported raw data (Excel/CSV) into Power BI.



Cleaned the dataset using Power Query (e.g., removing duplicates, adjusting formats).



Modeled relationships between tables in the data model view.



Built visualizations:



Bar Chart: Sales comparison by region.



Line Chart: Trend analysis over months.



Slicer: Added filter to allow interactive exploration.



Customized formatting: titles, colors, labels for readability.



Three Key Lessons Learned:



Dashboards must remain simple and uncluttered – too many visuals reduce clarity.



Interactivity through slicers and filters is essential for end-user usability.



Choosing the right visualization type is critical – bar charts for comparison, line charts for trends, pie charts for proportions.



Deliverable: Notes summarizing the dashboard creation process and three lessons learned, supported by a screenshot of the created dashboard.
