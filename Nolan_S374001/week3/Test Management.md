**ISTQB Foundation Level, Chapter 5: Test Management (1h)**



**Objective**: To understand the fundamentals of test management and the responsibilities of a tester versus a test manager.



Key Learnings \& Outcomes:



**Test Organization:**



Test Manager is responsible for planning, monitoring, and controlling test activities.



Testers design and execute test cases, report defects, and verify fixes.



Independent testing provides objectivity and reduces developer bias.



**Planning \& Estimation:**



Defined the test scope, objectives, resources, and approach.



Learned that effort estimation relies on complexity, past metrics, and team capacity.



**Monitoring \& Control:**



Progress is tracked through metrics such as test cases executed, passed/failed, and defect counts.



Control involves corrective actions, e.g., adding resources or adjusting timelines.



**Configuration Management:**



Importance of version control for testware (test cases, scripts, data).



Ensures traceability between requirements, tests, and software builds.



**Risk and Testing:**



Product risks (e.g., poor performance, security gaps).



Project risks (e.g., resource shortages, delays).



**Defect Management:**



Understood the defect lifecycle: New → Assigned → Fixed → Retest → Closed.



Learned how to report defects effectively, including severity and priority.



Deliverable: A structured summary highlighting the six key components of test management.
