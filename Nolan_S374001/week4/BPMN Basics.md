**Business Process Modeling Notation (BPMN Basics)**



Objective: To understand BPMN as a tool for visualizing business processes.



Key Learnings \& Outcomes:



Learned the core BPMN symbols:



Event (circle) → start/end of a process.



Task (rectangle) → an activity performed.



Gateway (diamond) → decision or branching point.



Swimlane → represents roles or departments.



Modeled the Food Ordering System:



Start event: Customer initiates order.



Tasks: Select food → Confirm order → Make payment.



Gateway: Payment successful? Yes → Delivery, No → Order cancelled.



End event: Order delivered or cancelled.



Understood how BPMN supports both business clarity (stakeholders visualize the process) and technical alignment (developers can translate into workflows).
